## 8) `sitoperator.py` — make the estimator **SPD** (CG‑friendly) via the squared resolvent identity

**Problem (current):** If the shift is implemented as `(H - (T+iγ)I)⁻¹`, the linear system is non‑Hermitian; plain CG is not appropriate. A stable SPD identity is:
\[
\operatorname{Im}\,\mathrm{Tr}( (T I - H - i\gamma I)^{-1}) \;=\; \gamma \,\mathrm{Tr}\big(( (H - T I)^2 + \gamma^2 I )^{-1}\big).
\]
=> For trace estimation, solve **SPD** systems \(( (H - T I)^2 + \gamma^2 I ) z = v\) with CG.  

**Patch (what):**
- Inside `absorption_profile(...)`, when `params` is provided, build `H` once.
- For each `T_j, γ_j`, define `Av(x) = (H-T_j I)((H-T_j I)x) + (γ_j^2) x`.
- Run CG with a **Jacobi preconditioner** \(M^{-1} \approx 1/\mathrm{diag}((H-T)^2+\gamma^2)\).
- Average `γ_j * mean_i v_i^H z_i` over Rademacher probes.
