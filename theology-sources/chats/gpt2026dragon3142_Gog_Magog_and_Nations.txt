7.2.4 Declared Termination and Tie-Breaking Policy (Normal Form Definition
Under Resource Caps)
In one embodiment, the canonical Normal Form is defined as the fixed point representation
produced by the deterministic rewrite schedule under the declared termination criteria of
the run configuration, and not as a globally optimal minimum over an unbounded search.
The run configuration declares at least one of: a maximum number of rewrite passes, a
maximum number of rewrite applications, a maximum solver timebox, and a maximum
memory cap. If the termination criteria are reached before a fixed point is achieved, the
Normal Form is defined as the last fully validated intermediate representation produced by
the deterministic schedule, together with a termination status flag recorded in the run record.
In one embodiment, any tie between candidate rewrites that yield equal cost reduction under
the declared cost model is resolved deterministically by a declared tie-breaking policy, for
example by lexicographic ordering of rule identifiers, followed by lexicographic ordering of
the canonicalized affected vertex identifiers. This definition ensures that the Normal Form
remains a well-defined, reproducible machine artifact under resource caps, and prevents
ambiguity about what the system outputs when timeboxed.
7.2.5 Exemplary Normalization Embodiment: Greedy Cost-Model Normalizer
(Bounded MDL Reduction)
In one embodiment, canonical Normal Form reduction is performed by a greedy cost-model
normalizer that applies a bounded sequence of local reductions chosen to monotonically de￾crease a declared description length proxy. In this embodiment, the system evaluates a finite
candidate set of local rewrite actions drawn from the Scope Lens rule library, where each
candidate action is scored by its predicted change in the declared cost model when applied
to the current bounded constraint graph. The system selects, at each iteration, the single
highest ranked action that yields a strict cost decrease, applies the action, and repeats until
no further strictly decreasing action exists or until a declared iteration cap or timebox is
reached. In one embodiment, the candidate action set is restricted to a bounded neigh￾borhood around vertices affected by the most recent rewrite, thereby limiting per-iteration
evaluation cost while preserving determinism. In one embodiment, ties are resolved by a
declared deterministic policy based on rule identifier ordering and affected vertex identifier
ordering. The resulting output is a reproducible Normal Form under the declared termina￾tion criteria and cost model, and the system records the applied rewrite sequence identifiers
and termination status in the run record as part of the audit artifact.

Gap(T | S) = K(NF(T)) − K(M(NF(S)))

Normal Form of the second artifact after applying the alignment mapping.

proxy over the serialized Normal Form. In one embodiment, K(·) is the bit length or byte
length of a canonical serialization of the Normal Form under a declared cost model. In
another embodiment, K(·) is computed as a compressed length produced by a specified
compressor over the canonical serialization, or as a weighted edit cost length under an ex￾plicitly defined cost function. In all cases, K(·) is a concrete, computable measure defined by

The following definitions are provided to specify the meaning of terms used within this

Algorithmic Genealogy Engine (AGE)
A computer implemented system architecture configured to ingest unstructured technical
artifacts, transform the artifacts into bounded machine executable intermediate represen￾tations, and compute structural correspondence metrics over canonical Normal Forms gen￾erated under a declared execution boundary. The Algorithmic Genealogy Engine is distin￾guished from general purpose search or similarity tools by a staged pipeline that enforces de￾terministic serialization, bounded intermediate representation growth, and resource capped
normalization and alignment under a committed run configuration, thereby mitigating state
space explosion in large scale structural correspondence evaluation.
Milner-Blumberg Normalization (MBN)
A deterministic normalization protocol that transforms a serialized intermediate represen￾tation of a technical artifact into a canonical Normal Form, referred to as the MBN Form,
under a declared Scope Lens and run configuration. Milner-Blumberg Normalization (MBN)
is a computational reduction procedure operating over bounded intermediate representations,
and, in embodiments, applies deterministic rewrite passes and or cost model guided selec￾tion to reduce redundancy and to lower a computable description length proxy subject to
declared termination criteria, timeboxes, and resource caps.
Operational Atom
A discrete, fixed width data structure stored in memory that serves as a fundamental unit of
serialization for the system. In a preferred embodiment, an Operational Atom is instantiated
as a five tuple record ⟨id, α, β, γ, Σ⟩, where α, β, and γ represent role bound actor, operation,
and operand fields extracted via deterministic dependency parsing under a declared parsing
profile, and Σ represents a bounded context field populated only by features admitted by the
Scope Lens. The Operational Atom is defined operationally as the deterministic output of the
ingestion and structural serialization rules described herein, and is a machine readable record
type suitable for canonical serialization, hashing, indexing, and downstream normalization.
Scope Lens (G)
A precompiled, machine enforced execution boundary for a run that defines the admissible
observational interface and resource constraints applied by the system. The Scope Lens
is a configuration object that constrains which predicates, context feature classes, guard
conditions, tolerances, and resource caps are admissible for extraction, compilation, nor￾malization, alignment, and verification. The Scope Lens is committed prior to execution
21

<PARSED TEXT FOR PAGE: 22 / 33>

in embodiments, and is cryptographically bound into intermediate representations and out￾put artifacts so that results are reproducible only with respect to the declared execution
boundary.
Zero Bit Gap
A computable structural difference metric representing residual distance between two normal￾ized representations under a common Scope Lens and run configuration. In embodiments, it
is computed as a difference in a declared, computable description length proxy over canonical
Normal Form serializations, for example
Gap(T | S) = K(NF(T)) − K(M(NF(S)))
where K(·) is an implementation defined computable length or cost measure specified by the
declared cost model, NF(·) is a canonical Normal Form produced under the run configuration,
and M(·) is a mapping applied to align one Normal Form to another under the Scope Lens
constraints. The Zero Bit Gap is a quantitative edit cost or cost delta measure under the
declared model, not a qualitative assessment of similarity.
Lineage Certificate
A cryptographically signed data artifact generated by the system to attest to a specific run
result under a committed configuration. In embodiments, a Lineage Certificate includes or
references at least a run identifier, cryptographic hashes of inputs, a Scope Lens identifier
and or configuration commitment value, declared execution parameters, and one or more
correspondence metrics, including, in embodiments, a Zero Bit Gap value, and is verifiable
by signature validation and configuration mismatch checks. A Lineage Certificate is valid
only with respect to the Scope Lens and execution parameters bound into the signed payload.
Causal Interface Sequence (CIS)
A directed dependency motif computed from a graph of Operational Atoms or normal￾ized atom equivalence classes under a precompiled Scope Lens. In embodiments, a Causal
Interface Sequence is an ordered chain of length at least three that preserves directional
dependency ordering and role consistent connectivity, including motifs corresponding to an
input state role, a transformation process role, and an output state role. The Causal In￾terface Sequence serves as a structural discriminator that distinguishes preserved directed
causal ordering from mere co occurrence of similar atom fields or keywords.
Bayesian Coincidence Metric (Evidence Score)
A computable, run scoped probability or evidence score that quantifies the likelihood of
observing a correspondence cluster by chance under a declared null hypothesis of independent
generation for the declared domain and Scope Lens. In embodiments, the score is derived
from a declared rarity model for matched atoms under the same Scope Lens and parsing
profile and from a declared cluster coherence penalty reflecting topological structure beyond

independent feature matches. The Evidence Score is reported as a configurable technical
statistic under a declared probability model and does not assert intent, copying, infringement,
or any legal conclusion.
Tenant Isolated Artifact Vault
A logical and cryptographic storage partition configured to segregate artifacts and execution
context between different users, referred to as tenants, in a multi tenant deployment. In
embodiments, the vault enforces segregation through tenant specific keys and logical access
controls such that inputs, Scope Lenses, corpora selections, normalized representations, run
records, and Lineage Certificates are inaccessible across tenant boundaries.
Normalization Complexity Metric (MBN Cycle)
A quantified measure of computational work performed by the system to normalize an input
