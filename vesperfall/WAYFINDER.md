Wayfinder interaction repair / September 19, 2026.

The owner approves the new gameplay but cannot operate the environment or finish a chapter. The authored model already supports winches, relays, return latches and exits. Its objective text is written into an XR HUD hidden by the default palm display; the palm itself previously contains only combat status. Earlier campaign tests used Xbox interaction for completion rather than completing the chapter using Goldwind grip in headset. Their passes do not invalidate this feedback.

This patch adds an object-local prompt when the existing model says an interaction is available. The current configured bow-hand interaction remains; in default left-bow Goldwind this is left grip. Point or reach with the free controller and grip to use that same nearby mechanism. It does not remotely complete a lens from an inaccessible floor. Line of sight and plausible hand reach are required, and the existing model still decides which action can run. Pickup, bow draw and quiver ownership keep priority. An interaction grip remains consumed until release so it cannot become a disk throw or repeatedly toggle a winch.

The on-demand palm card now states the current objective, restored signal count, direction/distance to the next signal or ready exit, and the actual completion requirement. Near a locked exit the prompt explains the missing signals rather than claiming success. At reward, the headset states which chapter follows the blessing choice. The original requirements remain: light both Causeway relays or Archive lenses, use the exit, choose a blessing. Defeating every monster is not required in these chapters.

This is a scoped 0.17.0 hotfix with versioned script cache keys, not new saved geometry. All five generators, objectives, profile/envelope keys, rewards, explicit preferences, classic crossbow, Xbox mapping and hand UI remain. The canonical 76-task workbook is unchanged; the repair belongs to existing interaction/accessibility/progression obligations.
