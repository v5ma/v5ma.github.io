# Floor Feedback: playtest-driven visibility repair

The owner reports no interaction text or live map while playing. Prior model/pixel tests do not overrule that physical report. The current source only rendered notices as desktop text or paused-menu summaries, and gated its wrist map on a raised free hand. This pass adds actual reference-space floor geometry for both requirements instead of treating the hidden DOM as sufficient.

A persistent floor map updates at up to 5 Hz during play, with the actual current district map, objective and Way In guidance. It does not depend on hands, controller lift or a head-pitch threshold. Its default is on, with an independent size/visibility setting; previous wrist-card settings and gameplay remaps remain unchanged. The ward supplies the full resolution map canvas rather than the tiny desktop thumbnail.

Interaction text uses each district's real message and timer. New notices appear on one floor plate, stay opaque for 1600 ms and fade over 400 ms, disappearing at 2000 ms. An unchanged long source timer cannot resurrect expired text. Repeated real interactions can create a new caption. Twelve recent notices remain readable through an on-demand native menu, in complete short pages, without extending the gameplay overlay duration. The plate and map follow the floor anchor, not the head or the simulated character; ordinary head motion does not move them. Deliberate placement/recentering updates the anchor. A late usable floor reference corrects an earlier estimate without copying head translation.

Diorama height is now 3 times the old height by default: 2.04 m versus 0.68 m at the default scale. Width, depth, character-centering, full-depth portal clipping, world-up and both/open aperture rules stay intact. A new 1-6x height multiplier changes only the aperture, not the world transform. Overall diorama size supports 25-300 percent of the original default. Menu size supports 0.35-1.6 and floor-map size 0.6-2x. Size/placement preferences have a separate validated key; old control and mission saves are not migrated or rewritten.

The first Spatial UI page exposes menu size, diorama size, box height and floor map controls. The same existing controller/pinch hit-testing is used. Menus remain hidden during gameplay. Recent messages are on both district menus. The old standalone recovery entries remain archival; this repair targets the unified main entry and all eight of its XR modes.
