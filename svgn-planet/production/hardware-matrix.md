# Real-device acceptance matrix

No physical device session has been signed off for Homecoming. Chromium/SwiftShader automation tests behavior, not the performance of the user's PC or a physical controller.

## Proposed desktop reference

Windows Chrome/Edge, 1920x1080, RTX 2060-class GPU and Xbox controller. This is a proposed target, not a claim about the user's current machine.

CPU/GPU and memory: Not recorded.
Browser and OS version: Not recorded.
Controller model, firmware and connection: Not recorded.
Quality and power mode: Not recorded.
Route and duration: Not recorded; target a warmed 10-minute ride and 30-minute soak.
Average fps, p95, p99, intervals over 50 ms and simulation/wall ratio: Not recorded.
Controller-only start, menus, sliders, repair, photo, journal, reset cancellation, disconnect/reconnect: Not recorded.
Audio overload, accessibility, approval, observed defects and date: Not recorded.

## Additional coverage

Low-power Windows integrated graphics: Untested.

iOS Safari touch: Untested.
macOS browser and controller: Untested.
Failure recovery on physical hardware: Untested.

## Recording results

Use Menu / Ride performance report / Show and copy the report. Share only information the tester agrees to share. No telemetry is uploaded automatically. Add measured sessions as production/evidence/hardware-YYYYMMDD-device.md. Failed, incomplete and skipped sessions remain recorded as such.
