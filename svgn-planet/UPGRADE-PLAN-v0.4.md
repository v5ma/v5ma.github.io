# SVGN.io Paper Delivery v0.4 — noticeable-world pass

This release is intentionally about changes a player can see and feel immediately. It does not add another title or separate demo.

The target is a denser playable neighborhood: three north/south streets, five cross streets, more licensed modular buildings, visible intersections/crosswalks/signage, bonus addresses, stunt gates, and a dramatically stronger Shift boost. The original eight-paper route and save key remain compatible.

Acceptance requires: the map and renderer expose at least eight road segments, original deliveries still work, branch roads are physically traversable, bonus stops and stunt gates award once, saved extras restore, Shift raises riding speed well beyond normal speed, and the close camera remains readable. Graphics use only bundled/local art and existing CC0 assets.
