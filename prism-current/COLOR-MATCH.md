# Color Match 0.13.0 / playable AR feedback pass

This pass implements the owner's direct per-hand color switching and optional color-match rewards. It does not make Easy harder, add enemies, shorten timing, alter health, remove healing or change the late boss entrance. The two existing chapters, AR Tide islands/clouds/grass, water/fire/trees, soundtrack, scene controls, interruption safeguards and retained games remain.

During tracked AR/VR combat, left X changes the left saber between MINT circle and ROSE diamond. Right A independently changes the right saber. Both hands may use the same color. Color is a selected tool state, not a requirement to use a particular hand. Trigger lasers, grip shields and B/Y pause/resume retain their roles. A/X still confirms the existing menu when not playing. Held input, newly added controllers, tracking loss and menu-to-play transitions do not create repeated or spurious color changes.

A valid fruit cut retains the original base reward of 120 points. Matching the fruit's badge adds 40 before the existing combo multiplier. The base and bonus are rounded independently; the combo increases once. Wrong color never removes points or invalidates an otherwise valid cut. Easy/Normal still allow either hand and any direction; Hard/Ultra still require the original direction and physical-swing tests. Lasers retain the old fruit reward without a slicing-color bonus. Purple blocks, healing and spiked-bomb rules are unchanged.

The blade and its small symbol badge show the actual palette. Fruit badges add a circle or diamond beside their original direction arrow. The existing controller/floor status shows both hand colors and controls; score feedback separates BASE and MATCH when a bonus is awarded. The stage HEALTH gauge remains in the same position and continues to prioritize actual damage/healing messages. No new permanent head-mounted panel is added. The AR Field Guide explains the optional bonus and still disappears throughout combat.

Screen controls remain supported: keys 1/2 change left/right colors; F still changes the active hand. The existing touch strip includes a Color button for the active hand. Standard gamepad L3/R3 changes left/right colors; A/X still performs the existing slash actions. These are mode-specific controls, not changes to every button mapping.

Because the scoring ceiling changes, new scores use prism-current.river.chromatic.records.v1. Previous difficulty scores in prism-current.river.pacing.records.v1 are read-only and displayed as previous bests in the semantic record area. They are not overwritten, migrated to a comparable ranking or silently deleted. The old original River and rhythm keys remain untouched. Difficulty, presentation and Arcade/Cruise still have separate record identities.

Color palettes and badges are prebuilt/shared; swaps do not allocate new geometry, textures or materials and do not recolor shared health/boss materials. Two 64x64 symbol canvases are uploaded in existing loading before music. No new scene pass, renderer, postprocess shader, camera movement or background loop is introduced. Resource checks and real rendering are separate evidence.
