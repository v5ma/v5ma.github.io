# Prism Rotunda 0.11.0

This playtest update is scoped to Prism Current. It adds an in-scene adjustable pedestal menu, compact controller or floor status, direct chapter AR/VR/screen choices, saved AR water opacity, and removes the arbitrary positional pause while preserving tracking-loss handling. The private hub and all other games remain outside this change.

Source and publication acceptance are pending. No implementation checkbox, branch, or documentation file establishes that the changed game is live. Keep existing saves, chapters, music and combat rules. Physical Quest/Xbox/touch approval remains open.
