The V1 receipt proves that the exact sources and routes were loaded. The V2 addendum proves that the worker actively reconstructed their operative rules. Neither receipt proves that the later comparison applied those rules correctly; method compliance, independent review, meta-audit, and post-task drift review remain separate fail-closed gates.

## Immutable-input rule

The addendum must bind immutable regression snapshots or batch-local input manifests. Do not bind a mutable program README that the same batch will edit, because doing so makes the preflight receipt unverifiable after the work changes that file.

## Authorization rule

A new or resumed batch is invalid until both of these pass in order:

1. the existing V1 preflight recall receipt and verifier; and
2. the V2 active-reconstruction addendum and verifier.

Historical V1 receipts remain historical records. This additive gate does not rewrite, rehash, downgrade, or invalidate them.
