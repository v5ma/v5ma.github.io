This is the Egyptian Seed and emanation follow-up to the September 18 comparative-religion edition. [Open the eight studies](index.html), [the 27 source-scoped profiles](profiles.html), [the twenty-connection relationship register](relationships.html), or [the source scopes](sources.html). The complete plain-text study export is READING.md.

The author proposes an Egyptian Seed hypothesis and uses abstraction to discover possible genealogical markers. The study preserves this positive research direction while distinguishing a structural family, a plausible contact mechanism, an explicit ancient literary appeal, and a recoverable textual transmission. It does not declare an uninterrupted Egyptian priesthood-to-every-modern-religion chain proved. The proposed moral-time-horizon study is not represented as an experiment already performed or a proof of one origin for secular environmental ethics.

The eight new studies address the method, Egyptian ascent and judgment, Egypt/Plato/Hermetic relationships, Plotinus and later transmission, wider traditions, Egyptian-Iranian contact, diverse afterlives and moral concern beyond life. The five-dimension profiles identify which witness is being compared and where evidence is incomplete. A missing feature is not silently a proved absence. No religion is scored or ranked; partial matches and source-recovery leads remain visible.

The source register distinguishes newly recovered material from the reading scope inherited from the earlier comparative edition. Source-updates.json corrects initial Plotinus retrieval scopes: the broad MIT Ennead pages did not expose every later tractate, so II.9 and the Egyptian-image passage have separately identified witnesses. Museum descriptions, a critical edition's abstract and full translated passages are not labeled as equivalent access. No wholesale copying of modern copyrighted editions is included.

Canonical inputs are the four studies-*.json files, profiles.json, relationships.json, sources.json, source-updates.json and manifest.json. data.cjs resolves source IDs, including legacy IDs in the preserved parent register. build.cjs generates twelve static HTML pages, index.json, READING.md and a hash report. Local filtering searches the full study text on the study index, not just headings. All substantive reading remains available without JavaScript. This local index is distinct from the main Wiki's global search.

Integration adds reciprocal links and a contextual introduction through the existing comparative generator. It does not edit the nine prior study bodies or append another layer to canonical principal-reader articles. Apocalyptic Repair Theology already leads into the earlier comparative series, which now directly exposes this new extension. The old directory, claim audit, forecast registers, scriptures, social-media snapshots, original chats and main reader contracts are preserved. The parent navigation and its regenerated HTML/hash report are the only changed content outside this new folder, plus a short parent README note and the dedicated workflow files.

Build with node theology-wiki/comparative-religion/egypt-emanation/integrate.cjs followed by node theology-wiki/comparative-religion/build.cjs. The parent generator automatically builds this extension. Run node --test theology-wiki/comparative-religion/egypt-emanation/research.test.cjs and python theology-wiki/comparative-religion/egypt-emanation/check_pages.py. Existing parent and main-reader suites remain separate gates. Production checks compare actual public file hashes and repeat real browser behavior; a script's existence is not evidence of its success.

Save source checkpoints before executing the next stage. The one-shot branch integration writer must be disabled before merge. Continuing validation is read-only and has no recurring schedule. Workflow and publication receipts belong in the PR and the release note, with any failed attempts preserved rather than silently converted to passes.
