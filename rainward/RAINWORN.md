# Rainward v0.12.0 / Rainworn

The player and nearby human patrols now use adapted male and female Quaternius character meshes. The author makes the Standard edition of Universal Base Characters available at no charge under CC0. This release uses only that free edition, not the paid Source edition. The two included adult base meshes are the male and female Superhero proportions. Face, eye and hair textures and the selected hairstyles are original Quaternius assets, not scanned likenesses of real people. The result is a more detailed stylized human, not a claim of photorealism.

The build pipeline fits source skin influences into Rainward's existing seventeen-bone bind pose. The detailed source face, hands and hairstyles are combined with Rainward's original tailored jacket, cargo trousers, boots, backpack and pockets. Keeping the original garment geometry avoids turning the source base body into painted-on clothing. The source body is retargeted for fit validation; its placeholder garment surfaces are not rendered over the game outfit. Weapon attachments stay on the original wrists. The original animation system still drives standing, crouching, prone movement, aiming, reloading, striking, bandaging, crafting, vaulting and downed poses. The imported mesh does not get separate movement authority or change the combat hitbox. Authored animation replacement, finger animation and contact IK remain future work. The free Universal Animation Library was inspected as a possible later source, but its animations are not claimed as integrated by this release.

Both glTF files and their compact face/normal/eye/hair images are self-hosted under assets/humans. The combined character transfer is under 4.5 MB. Meshes share decoded geometry within a chapter, but actors retain independent existing skeletons. Downloaded bytes can be reused between chapters; stale parsed scenes cannot attach after a chapter is disposed. Human patrol detail switches to the original rig at distance, with hysteresis to avoid boundary flicker. The player retains the adapted model in Reduced Graphics; simplified materials and shorter patrol detail distance keep that mode useful.

Controls and Settings now contain Detailed human models and Rain-worn surfaces switches. Both are reachable using the existing D-pad, A and B menu controls. Turning either off does not reset position, inventory or save data. A failed human download leaves the original character playable and offers a Retry button. Listening silhouettes are rebuilt when an actor's visual representation changes, rather than displaying the old body over the new one.

The rain-film shader composes with existing scanned and procedural world textures. It changes patchy surface roughness, darkening and a physically based clear-coat layer on eligible world materials. It does not change geometry or create another full-screen render target. Per-chapter rain amounts provide an art-directed difference between wet streets, the conservatory and the snow chapter; this is not a physical roof-exposure simulation. Clothing uses restrained fabric sheen. Reduced Graphics disables the rain-film treatment and uses the existing diffuse material path. No render-engine update or third-party shader service is required.

All six expeditions, both controller presets, original soundtrack, finite ammunition, required tasks, field records, puzzle gates and chapter-save keys remain intact. RW-034 and RW-039 now have implemented visual foundations, not final art-direction sign-off. Fully original hero sculpting, authored animation clips, pose contacts, target-hardware frame rates and subjective art approval are not marked complete by automated tests.

Author page: https://quaternius.com/packs/universalbasecharacters.html . Official download page: https://quaternius.itch.io/universal-base-characters . The paid Source package was not accessed.

The source archive SHA256 is fdbf1804c90dfc1ea03e992bff7da2dfd1a79318e13270a660180f9308455f40. Derivative file hashes, byte counts, mesh counts and fit bounds are recorded in assets/humans/manifest.json. The reproducible converter is tools/build-rainworn-models.py, using NumPy and Pillow; it takes an extracted, verified Standard source directory. The source package remains available from the author; only the necessary derived runtime models are committed here.

The shader implementation is original Rainward code using the already vendored Three.js material API. Relevant primary documentation: https://threejs.org/docs/pages/MeshPhysicalMaterial.html . Clear coat and sheen are existing physically based techniques, not claimed as new research or as features newly released by Three.js.

## Acceptance boundaries

Source tests verify the actual derivative bytes, 17-bone weights, clothing/material separation, self-contained textures, posture envelopes and shader composition. Browser tests load and render the real glTF, compare original/imported and dry/wet views, operate the new settings by standard-gamepad input, change chapters and inject a single isolated model-download failure. Existing mission and controller suites run separately with their original gameplay rules. These tests do not certify physical Xbox/Bluetooth hardware, enjoyment, subjective realism, artistic approval or target-hardware frame rates.
