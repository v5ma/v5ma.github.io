# Dino Atlas: Wild Frontier / Ranger Operations

The existing Dino Atlas now has a 620-unit-wide fictional reserve, 14 species, 40 residents, eight new managed enclosures, six outposts, and four vehicle types. Play at index.html over HTTP(S). The original recorder mission, field journal, fossil lab, quizzes and walking expedition remain preserved. This is a further upgrade of Wild Frontier, not a separate replacement game.

Xbox standard layout: left stick steers or moves; right stick looks and aims; A interacts; Y boards/exits; X reloads; RB changes tool; Menu pauses; View opens the map. RT accelerates ground/water vehicles and LT reverses/brakes. In the helicopter RT climbs and LT descends. On foot RT fires and LT aims; when mounted hold LB and RT to fire without accelerating. Menus support D-pad/stick focus, A select, B close, left/right settings adjustment, right-stick scrolling and LB/RB panel switching. Read the in-game Controller Guide for the complete mapping.

Keyboard: WASD/arrows move, E interacts, F boards/exits, R reloads, Q changes tools, Shift boosts/sprints, Space brakes, J hops, H honks, G rights a vehicle in place, M opens the map, C changes camera, and Escape pauses. Helicopter lift uses Z and descent uses X. Hold the right mouse button to aim and left to fire. Touch controls include movement, firing, reloading, switching tools, boarding and flight lift.

The pressure hose and electric zapper deter/herd fictional animals without injury. X/R reload transfers finite water/battery reserves; resting at an outpost replenishes everything. Fill an enclosure's feeder, guide all residents inside through its open gate, and close the gate to secure it. Vehicles take no damage. Blast crates and dinosaur impacts can overturn them, and recovery rights the same vehicle where it is, including inactive vehicles. The helicopter must land before exit; the boat is boarded/exited at the marked wetland dock.

Audio is now a locally synthesized game system rather than one engine tone. It includes separate jeep combustion layers, electric buggy whine, helicopter rotor harmonics, boat motor/water layers, footsteps, wind, wetland ambience, nighttime insect texture, procedural dinosaur calls, horn, ranger-tool discharge, reloads, impacts, explosions, recovery, discovery/outpost/mission cues, menu focus sounds, danger stings, and a dynamically scheduled original score that changes during predator pursuit. No music or sound recording is downloaded. Master, music, effects and ambience levels are individually adjustable in the pause menu with the controller and saved under dino-atlas.audio.v1. Browser autoplay rules may still require one trusted pointer, keyboard, or touch gesture before WebAudio can begin on some devices; gameplay and every menu remain controller-operable if audio stays locked.

The original data uses dino-atlas.progress.v1. The recorder campaign retains dino-atlas.ranger.v1. The expansion uses dino-atlas.frontier.v2. New observations merge into the original journal only for its original six species; all 14 species are tracked in the in-game ranger journal. No existing keys are cleared. The old 2D/3D experience remains at walking.html and the standalone guide remains at field-guide.html.

No account, API key, external runtime service, paid asset, analytics or installation is required. Three.js and Rapier are locally hosted with their original licenses. All art, reserve geometry, music and sound effects are procedural, stylized gameplay. The dinosaurs are not presented as validated paleobiological reconstructions. This is an independently implemented vehicle/world interface inspired by Bruno Simon, not a copy of his code or assets, and is not an official Jurassic Park product.

Run npm start for the local static server. Run node --test tests/unit.test.mjs tests/ranger.test.mjs tests/frontier.test.mjs for original and expansion tests. Run python tests/frontier-browser.py from the repository root, with Playwright and Chromium installed, for native HTTP/WebGL and simulated standard Xbox input. Run python tests/audio-controller-browser.py for controller-only settings, disconnect recovery, custom dialogs and audio-mixer persistence. The optional TEST_BASE_URL targets a hosted build. The old ranger-browser.py is retained as the first-release historical harness.

The workflow artifacts, not this README, are the source of passing-test claims. Automated gamepad simulation does not certify physical Xbox, haptics, speaker output quality, real mobile hardware, Safari or XR compatibility. The expansion does not implement Quest/AR/VR, multiplayer, full ecology or cinematic asset fidelity.
