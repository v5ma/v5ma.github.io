# Public expedition handoff

The earlier private prototype has been extended into a public static 2D/3D walking expedition. The field guide is preserved at field-guide.html. Only the dinosaur app is copied from the private project; no unrelated private repository files are published.

The public repository deployment preserves the Mario Maker editor, adapts the actual SAN shell to the existing public theology collection, and retains earlier root links at legacy-demos.html. A .nojekyll file is important: the renderer's underscore-prefixed helper and the wiki's Markdown files must be served verbatim.

Actual verification evidence is generated by the interactive validation workflow and attached as an artifact containing browser screenshots, runtime checks, and a JSON report. Do not treat the earlier prototype's inline browser-harness results as evidence of the new app's WebGL or HTTP behavior.

For rollback, revert the public upgrade commits. Existing game saves are not migrated or cleared. Paper campaign records and blueprint backups use new namespaced keys. Dino Atlas continues using its existing progress key; clue discoveries have their own namespaced key. Public hosting does not imply compliance certification or a completed scientific review.
