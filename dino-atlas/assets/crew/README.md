# Kenney crew assets

Original pack: Animated Characters Survivors 1.1, by Kenney.
Source: https://kenney.nl/assets/animated-characters-survivors
License: CC0; original License.txt retained as LICENSE.txt.

Only the two living-human skins are used. ranger.glb converts the supplied characterMedium.fbx plus Idle and Run animation clips to glTF 2 using Three.js r177. No zombie textures are shipped. Materials use the original separately hosted human skin PNGs. Original mesh has 4812 non-indexed vertices and 44 original skin joints (45 joints in the converted glTF skin); the neutral model is normalized to 1.85 m in game. Animations are retained, not claimed to be newly authored or anatomically lifelike.

The conversion has deterministic SHA-256 042f655423ee399c428c59c01e6c65be7e970c36db0c49f595e6542e1b99c370. An asset build tool and source receipt reproduce it. No runtime network request leaves the game's origin.
