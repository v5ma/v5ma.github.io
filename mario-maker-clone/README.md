# Mario Maker Clone Project

Web-only static package for the Mario Maker-style Sprocket Works project.

- `index.html` is the builder and playable project surface.
- `svgn-paper-route/` is the current SVGN Paper Route deployment.
- `svgn-paper-route/design-decisions/` contains the exact feature/design log and a readable rendering of the source task decisions.

The package excludes the desktop build, installers, database setup, and private development files.

Public route: https://v5ma.github.io/mario-maker-clone/
