# Cloudview reference implementation

The owner selected the generated sky-high delivery image in the September 4 conversation as the art target. Its defining features are broad gold-edged loop roads, dark riding surfaces, blue boost lighting, bolts and supports, floating islands with greenery and cities, waterfalls, a postal airship, red mailboxes, and a helmeted motorcycle courier. The visual inspiration named by the owner is Sonic the Hedgehog, Motocross Maniacs 2, and Super Mario Maker 2, combined into an original game. No assets from those games are copied.

This implementation authors the roads, islands, targets and courier as actual geometry in the existing Three.js WebGPURenderer. It does not paste the concept screenshot into the gameplay canvas or replace the game with a picture. Cloudview-world.js provides merged static geometry and an animated rider. Cloudview-ui.js and cloudview.css provide the compact blue-and-gold cockpit. Small authored canvas textures provide signs, sky colors, metal finish, waterfall streaks and soft cloud impostors. The selected image remains the visual direction, not a claim that a real-time scene reproduces every painted detail.

The second visual pass replaces the initial ellipsoid cloud banks with layered soft cloud planes, introduces atmospheric distance, adds cliff fragments and more varied town silhouettes, textures the track panels and renders the actual collectibles as sealed envelopes. The camera moves closer while riding a loop and widens during airborne transfers. This is view framing, not adaptive graphics-quality reduction.

The existing loop centerlines, launch sectors, input physics, airborne catch collision, route layout, delivery collision, quotas, score, save data and checkpoints remain authoritative. The two-wheel visual rides the existing contact point; its art overhang is not a second wheel-physics simulation. Decorative islands are not new traversable collision surfaces. The gold sector is identified by warm lights and the launch prompt even though the full road has gold armor. Custom level copies derive mailbox and collectible visuals from their actual grid rather than campaign metadata. Original scene lighting is restored when leaving the featured world.

Shader resources use merged geometry or small instance batches, retaining the existing instance-limit guard. There is no automatic reduction of visual quality. Native WebGPU hardware and real mobile frame rates need separate testing. The visual test records the real renderer and a normally controlled loop-to-loop transfer and exercises an editable copy. The original full sky replay checks the three courses, lower detour, failure gate, saves, pause, and editor restoration. Actions artifacts contain the actual tested-commit receipt and screenshots; a source description is not independent visual proof.

Technical references: https://threejs.org/docs/pages/MeshStandardNodeMaterial.html ; https://threejs.org/docs/pages/InstancedMesh.html ; https://threejs.org/docs/pages/WebGPURenderer.html . Existing pinned renderer files and third-party license notices are unchanged.

Scope: Paper Delivery rendering and its view/UI only. The dinosaur and theology applications and private repository are not edited. The feature branch records integration source before testing. Rollback is a revert of the art merge, not deletion of browser saves or resetting unrelated repository history.
