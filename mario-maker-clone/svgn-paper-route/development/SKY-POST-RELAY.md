# A reward for following a new line

This revision adds one complete optional high-to-high whip route, rather than inflating the surface count. The existing fifteen Sunrise Borough surfaces are byte-identical. A real peg above the High Garden flight leads to a higher airmail balcony, then rejoins the existing Festival glide. No movement coefficients, collision tolerance, gravity, steering, score function or finish gate change. Ground, high, canal and both later road-entry recipes remain valid; later chapters and expert courses retain their existing builders.

The added receiving surface is a cubic from (4740,450) through (4970,590) and (5930,445) to (6150,625). Its peg is an actual level tile centered at (4482,666). These points, the open track metadata and the peg feed the game, map and Workshop. Violet markings distinguish the new opportunity. There is no invisible platform or magnetic attraction between them.

Design sampling carries the same rider from a declared road-jump sample through m0-m5, the peg, the new balcony and m8. Forty-nine declared cast-position/release-phase cases reach the balcony and return without a modeled deck-clearance warning. Six precision/forgiving and one/two/three-turn cases and nine initial-speed/cast variations test additional bounded conditions. The swept 20-pixel envelope includes source and receiver deck bodies, not only unrelated rails. Rejected early candidates crossed through a deck despite eventually reporting a catch. These fixtures do not prove every timing is safe or that the sequence feels good to every player. Native full-input verification remains an independent gate.

The Route Passport makes discovering a line visible without inventing another currency. It observes completed ordered catches, and requires the named actual whip release or underside contact for those special routes. It writes only after a real Sunrise campaign finish. Duplicate catch events, repeated finish callbacks, simulation results and Workshop previews cannot farm a stamp. Incomplete chains reset on road landings/retries. Stamps are local, exportable keepsakes; they are not a claim of authenticated or synchronized accounts.

The new module is an additive builder over the current authored route. Saved drafts are not migrated. The old dense layout stays available as before. The existing read-only CI and public-hash verifier now cover twenty-eight owned runtime files. Native UI and replay tests must inspect the rendered marker, actual whip release and catch, full finish, passport persistence, pause preservation, mobile layout, complete editable export and no-write preview isolation. Earlier model results are not a deployment receipt.

Follow-up work remains: human timing/comfort trials, still broader reverse-route exploration, the later chapters' authored-layout pass, controller/device performance, and account/multiplayer development in a separate explicitly authorized scope. This change touches no Supabase schema, account entitlement, payment, coupon, Theology, Aether Reach, Rainward, Dino Atlas or Studio content. Rollback is a scoped merge revert, not a reset or save deletion.
