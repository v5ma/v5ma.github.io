# Finish the campaign, not only its editor preview

The original Cloudpost candidate added a real high-to-high peg route, but its native campaign test never started that geometry because the menu retained an earlier immutable campaign provider. The shared controller now resolves the current provider at use time. Retry and Next use the same source as the Workshop, without respawning an existing run or migrating player drafts.

A second startup defect was found during the completion pass. Campaign registration lived at the end of the optional Ride Lab import chain. A failed authoring-tool download could therefore prevent the new gameplay content from ever registering, even though the installed version advertised it. Release boot now imports the campaign independently and starts optional tools afterward. Normal route-start, retry, next and featured-copy controls remain visibly unavailable while content is pending. Registration restores their original disabled states. A failed content import reports the problem and provides an explicit reload; it never silently starts the old chapter. Save/export and authoring access remain available, and a reload warns about an unsaved draft.

Native startup tests hold the campaign response, fail the optional tool response, and fail then restore the campaign response. They assert one real start, the expected sixteen physical surfaces and no phantom progress. Network fault injection is distinct from altering live rider state. Campaign acceptance also retains complete ordinary-input relay, non-whip upper, lower canal, underside recovery, road re-entry and ground runs; the current Bezier tools, two-sided yard, expert loop, Hookline, Ride Lab and guide remain regression gates.

The completion workflow tests the committed source directly with read-only permissions and records all failures and runtime hashes. It also packages a source archive for reproducible review instead of inserting encoded transfer fragments or rewriting source within CI. Existing failed and approval-blocked attempts remain in history. A new successful run must not be described as proof that the previous run passed.

This remains an optional 400-point route connection, not paid access, a required level gate, automatic attraction, a new physics mode or a replacement for the authored routes. Body/rope-clearance model samples are finite; arbitrary input and physical-phone/controller performance are not certified. Release is established only after the exact native source passes and the public-file proof matches the merged runtime. Preserve concurrent unrelated applications and saved player documents; rollback is a scoped revert.
