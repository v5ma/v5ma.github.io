# Waterwheel Lab v0.23.0

Build: `sky-cycle-waterwheel-lab-2026.09.15`. This release continues the approved chapter-design work inside the existing Sky Cycle. `verification/waterwheel-lab-0.23.json` is the authority for exact accepted source, native checks and publication. This note does not itself certify a candidate as live.

## What this slice delivers

The two supplied design drafts are integrated in the canonical `LEVEL-DESIGN-METHODOLOGY.md`. `chapters/WATERWHEEL-BOULEVARD-R2.md` is the concrete chapter specification and promotion workbook. The methodology preserves the complete ground delivery adventure and ambitious connected optional aerial network; additional cosmetic or destination work must not displace the reference chapter.

The playable revision is an explicitly labeled, editable Workshop preview. It is not a ninth campaign destination and does not silently replace the older Waterwheel campaign geometry. The eight existing campaign builders, route IDs and indices remain unchanged. The existing Workshop owns playtest isolation: completing this preview awards no campaign medal, badge, stamp, daily result, ghost record or persistent credit.

Seven named sections connect South Quay Post Office, Parcel Market, Service Bridge, Express Junction, Millworkers Court, Waterwheel Galleries and Wheelhouse Depot. The road contains twelve delivery targets, five checkpoints, two broad terraced rises and four separated shield-supported patrol encounters. The wheelhouse and nine authored wayfinding signs are present in both the 3D and 2D presentations. The presence of twelve targets is not certification of every target or optional discovery.

A short Parcel porch detour returns to the road before the express entrance. The longer upper ride connects `ww-runway`, `ww-crescent`, `ww-gallery` and `ww-finish`, carrying the rider through the original two-sided rail physics and back toward the depot. Two lower recovery surfaces are authored but do not inherit a comprehensive recovery qualification from a successful main-line ride. Five transfer intentions are stored in the editable document, with approach/receiver/recovery/onward information. There is no new dedicated graphical transfer-annotation editor.

## Play and save protection

Open Routes, then choose **Waterwheel r2 design preview**. The dialog offers **Ride the new layout**, **Ride with the sky hidden**, **Open editable blueprint**, **Restore previous blueprint**, and Back. The same entry appears in the Workshop's Worlds and drafts.

The sky-hidden option actually builds the same ground journey without the aerial rails, rather than making invisible collision geometry. The whole preview remains editable with the original independent Bezier controls.

Dirty Workshop drafts and active playtests block replacement. A validated previous blueprint must be written to `svgn.skycycle.waterwheel-preview-backup.v1` before a non-preview document is replaced. A failed backup write blocks entry. Restoration is explicit; no old save namespaces or Workshop libraries are cleared. Future revision-aware campaign record handling is still a promotion gate; `canal-choices-r2` remains a reserved identifier rather than an active award namespace.

## Input and presentation

Keep the existing Xbox gameplay defaults and remaps, including direct jump, boost, paper, whip and nearby interaction. Menu focus/confirm/back use the existing controller system. The seated XR implementation still uses tracked-controller rays and native hand-select UI, not a new locomotion system. Physical Xbox and Quest 3 qualification remains separate from sampled Gamepad input and emulated tracking.

The stereo UI now uses a late transparent render group with opaque panel pixels, no fog/depth interference and a later pointer group. The normal scenery remains visible behind, not through, the controls. This is a targeted fix for the pinned rendering implementation, not a new headset-support certification.

During recovery, an actual South Quay capture showed introductory dialogue covering the riding instruments. Preview-only dialogue placement now measures the HUD and moves the existing toast above it. It calls the original notification owner and never filters out save or input warnings. Leaving the preview restores the original layout owner. Page-hide and restored-page lifecycle handling releases and reconnects its observers.

## Evidence classes and retained failures

Normal-input browser rides must separately complete the ground road, ground-only build, short returning porch and continuous express. The actual 3D scene is inspected before full-route traversal in the supported 2D renderer on CPU CI. These are not full 3D hardware playthroughs. Old-save seeds are labeled fixtures; tracing only reads after the real tick and never assigns position, velocity, score or a win.

The Waterwheel XR suite uses the real Three XRManager, real stereo framebuffer and deterministic hardware emulation. Six actual Workshop pause controls are sampled in both eyes. It requires uniform backgrounds, measurable text contrast and a separate render-only scene-visibility fixture to show that scenery cannot overwrite the sampled panel pixels. Visibility is restored in a finally block; physics and progression are untouched. This is not a full XR chapter finish or a physical Quest test.

The initial finish receiver ended at x=8710 and carried the model beyond the depot. Moving only the authored endpoint to x=8550 brought the declared continuous express cases back before the goal; the failed model is retained in the chapter record. Larger recovery coverage remains unproven.

The initial stereo screenshot exposed scenery painting over menu panels. The explicit overlay groups correct that rendering fault. A later pixel oracle also had two test defects: it expected a Portal atlas row where the Workshop pause page actually exposes Materials & FX, and it compared untransformed canvas sRGB bytes with the renderer's output bytes. Run `35033434378`, job `104597072306`, artifact `10422039636` retains that failed check and its visible opaque panels. The revised test checks all six real controls and tests contrast and scenery independence rather than accepting arbitrary screenshot colors.

The earlier default-replacement experiment on `sky-cycle/waterwheel-reference-0.23` is not the publication candidate. Do not merge it over this newer preview, Quiet Water or current save owners. Its unfinished record/layout experiment can inform a later deliberate promotion, not an accidental second v0.23 release.
