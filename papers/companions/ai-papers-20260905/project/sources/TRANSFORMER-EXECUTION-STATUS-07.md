# Transformer mapping and execution: Draft 7

Both papers have actual pretrained GPT-2 causal interventions, an online-trained correction layer and a prospective varied-intent/collateral-color assay. They do not have measured contemporary instruction-tuned or DeepSeek behavior. [Architecture-specific mapping](TRANSFORMER-BRIDGE-AND-ACCEPTANCE-04.md), [static GPT-2 stage](TRANSFORMER-EXECUTION-STATUS-05.md) and [learned GPT-2 stage](TRANSFORMER-EXECUTION-STATUS-06.md) remain preserved.

| Research object | Current implemented mapping | Evidence boundary |
| --- | --- | --- |
| Organized receiver | Frozen quantized GPT-2; final-token residual after zero-indexed block 8 and actual downstream computation | Not biological anatomy, a complete IOI circuit, or a frontier model |
| Learned correction | Existing 4-by-5 matrices plus rank-four training basis/center/scales/cap | Twenty adapting coefficients in Draft 6; no new fitting in Draft 7; base weights unchanged |
| Requested operation | Authenticated structured keep/swap cue independent of person names | Supplied intent, not learned interpretation of natural-language human guidance |
| Semantic fidelity | Both opposite roles and both cues evaluated, with native full-vocabulary output | Individual successes do not certify relational competence; learned/reflection arms fail all complete swapped-role pairs |
| Collateral behavior | Red/blue attribute queried under the same edit policy | Different terminal contexts and separate caches; not persistent shared-state or isolated-feature proof |
| Algebraic control | Standard affine reflection in the existing learned subspace | Numerically reversible, but not a reliable semantic swap; capped control duplicates it here because cap never activates |
| Update/action authority | Actual scope updates followed by readout selection and trusted virtual-send checking | Public key fixture; precomputed readouts reused after updates; correct supplied targets and complete mediation assumed |
| Context and state | Explicit incremental prefix cache and separately saved correction arrays | No multi-query persistent latent editing in the new assay |
| Current DeepSeek transfer | Version-specific residual, compressed attention/cache and expert-routing requirements | Mapping only; no model execution, learned transfer or runtime-performance claim |

[Draft 7 review](../reviews/gpt2-intent-07/REVIEW.md) links 64 fixed prompts, 512 measured readouts, 1,536 reused outcomes and 512 actual authority events. Every readout is recomputed through separate audit code; 51 cumulative application tests pass. There is one frozen checkpoint, eight new constructed families and no new download. Each serial numerical batch takes about 35 seconds on one thread.

The [primary-methods intake](INTENT-SELECTIVITY-METHODS-07.md) credits RAVEL's cause/isolation tests and causal abstraction's high-/low-level mappings, including explicit read-depth limits. Neither is a newly invented SAN method or a replicated external benchmark. ReFT owns the related learned-representation family; the reflection's known algebra is not a new method claim.

Next: context- and position-sensitive alternatives, a properly specified shared-state versus separate-query comparison, stronger matched-information methods, then bounded contemporary-model transfer. Already exposed Draft 6/7 cases cannot become an undisclosed tuning set. No result establishes an intelligence scaling law, reduced human oversight, ethical alignment, consciousness or a clinical effect.
