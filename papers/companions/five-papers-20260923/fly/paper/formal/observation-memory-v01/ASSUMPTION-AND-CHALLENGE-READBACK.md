# Assumption and strongest-form challenge readback

19 September 2026. Same-agent review plan and argument reconstruction; not independent mathematical or scientific review.

## Original argument, without compression

The SAN construction concerns a history-shaped receiving network that can reconstruct, use and revise a body-world relation, learn from returned consequences and retain changes in its receiving organization. It is not a claim that an identical instant of input must always produce the same response regardless of learned state. It is not a claim that a rendering should always be discarded when current recognition fails. The Draft 5 controller is a conventional reference, not that completed neural construction.

M7 compares runs with the **same whole initial controller state, functions, settings and permitted input history**. Under that equality, the controller cannot identify a hidden difference before distinguishing information arrives. Prior knowledge and active sensing remain available, provided their information and state are declared. M8 concerns a specified intervention on temporary state while retained state is preserved; it does not equate all memory with temporary activity.

## Challenge matrix

| Challenge | Exact premise or boundary | Audit witness | Consequence |
|---|---|---|---|
| Different learning histories, same current observation | M7 requires equal initial state, including learned knowledge | Two identical-input controllers begin with different state | Different actions are allowed; this does not challenge M7 |
| Unrecorded body feedback | M7 requires equality of both sensory and body-return histories | Same sensory stream, different returns | Later state/action can diverge |
| Changed policy or a hidden world-dependent callback | M7 fixes the functions and excludes side channels from the model | Two policies map the same internal state to different actions | Interface premise fails; equations cannot certify a Python security boundary |
| Equal actions interpreted as equal experience/world | M7 is one-way and contains no experience variable | Different states map to the same action | A behaviorally equal trace does not imply a physically equal world or an equal internal relation |
| Distinguishing input must immediately change action | No such converse is claimed | Existing two-world test changes reconstruction at 9, action at 11 | A delay can be compatible with a changed reconstruction |
| Error lower bound claimed without a metric | M7b uses triangle inequality and symmetry | A nonmetric distance table violates the bound | The metric assumption is essential |
| “Reset” silently erases calibration | M8 clears the episode field only | Bad reset replaces both fields | Retention is an implementation obligation, not something conferred by the operation's name |
| Every learning update commutes with reset | M8's update reads retained state and the same declared return, not transient state | Episode-dependent update fails to commute | This conditional identity cannot be generalized to arbitrary learning rules |
| Reset must preserve every action | M8 preserves only readouts of retained state and fixed command | Transient-dependent readout changes after clearing | Target reconstruction and policy behavior are outside that identity |
