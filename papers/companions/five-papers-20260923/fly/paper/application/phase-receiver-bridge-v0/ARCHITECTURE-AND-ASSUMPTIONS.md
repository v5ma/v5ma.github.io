# A directed phase receiver connected to an embodied reference task

19 September 2026. An exploratory **bridge**, not the recovered hue model, a measured fly visual circuit, or a completed SAN implementation.

## Why this construction is separate

The registered anatomy supplies ten sampled identities and reported directed contact counts. It does not supply synaptic efficacy, all signs, sensory input projection, oscillation frequency or a final fitted hue configuration. Those missing quantities are not smuggled in from the published motor circuit. This construction declares its own dimensionless dynamics and input mapping. Its role is to make the receiver-to-action connection executable and falsifiable while leaving biological reproduction as a distinct obligation.

Fifteen reported routes connect the ten selected cells. All other routes are outside this reduction; a missing route is not a measured zero. The two disputed counts are represented by lower and upper cases. Absolute incoming-row normalization is a modeling choice, not conversion of synapse count into conductance. Two source model-level Dm8 sign constraints are retained; two uniform settings of the other unknown signs are exploratory sensitivity cases, not a complete sign search.

## Connected operations and their ownership

1. The unchanged engineered world supplies only time, observed band indices, spectral captures and signed ranges. The four bands and range instrument are not a native fly retina.
2. A normalized capture difference from uniform tonic capture drives ten directed phase receivers. The input projection is a declared mixed-sign engineering matrix, not a recovered photoreceptor-to-cell map.
3. A learned complex readout receives the resulting population pattern. During public cued familiarization it averages three intensities of each of the two task exemplars, separately for the two available band masks. No world position, target label from the running episode or hidden gain enters that update. This is supervised exemplar learning.
4. Only the readout's acceptance and ambiguity results reach the inherited target-relative tracker. It uses permitted range and actual body return to maintain an observed, inferred or unresolved relation, and that relation determines movement.
5. Actual measured displacement updates the relation and retained actuator calibration. The issued command is not substituted for movement. The calibration rule is conventional engineering, not the reproduced biological memory model.

The new phase/readout branch therefore changes an actual causal input to the controller. The remainder of the tracker and motor-calibration architecture is conventional. PWD throughout all NAPOT operations, multimodal learned content, native motor coupling and the full SAN learning hierarchy remain **unimplemented**, not supplied by new labels.

## Equations, time and readout

For observed mask M, let x_j=q_j/sum(q)-1/|M| on observed bands and zero on missing bands. Zero total capture yields zero x; this is a no-contrast instrument convention, not a measurement of omitted spectral content. A declared matrix B has unit absolute row sums. With K in postsynaptic-row/presynaptic-column order, the relative phase follows

    d phi_i / dt = -a sin(phi_i) + b (B x)_i
                  + g sum_j K_ij sin(phi_j - phi_i).

All phases start at zero for each independently queried patch bank. This reset is a reduction choice: it does not simulate a continuously persistent spatial visual array. RK4 integrates for four dimensionless units. a=1, b=0.8 and g=0.12; no fly milliseconds or biological frequency is claimed. The output carrier is z_i=exp(i[theta+phi_i]); its tonic reference is exp(i theta). The downstream population representation is their complex relative product. A learned readout receives this product, not a hidden category.

The readout distance is the population mean squared complex distance to each learned weight vector. The two familiarized patterns determine both separability and a relative acceptance radius. At the three-band mask the two cues are identical, so their readouts must not become separable merely because they had different teaching labels. Earlier relational state can associate an ambiguous subsequent observation with a previous target; without such state, the first aliased observation must remain unresolved.

The absolute carrier is arbitrary. A second implementation runs the same relative-coordinate equations and directly returns cos(phi),sin(phi), without forming an absolute oscillator. The prediction is **equivalent decisions**. This is an important limit: a successful phase-labelled implementation does not identify an irreducibly oscillatory mechanism. An imposed common carrier is not evidence of endogenous tonic biological organization. The full SAN account is not reduced to this restricted bridge.

## Complete state and reproducibility

Persistent model settings: source-derived K, engineering B, integration/readout constants, source manifests, implementation mode and inherited public controller settings. Retained learned state: two readout vectors for each band mask and familiarization counts; actuator gain. Episode state: target-relative relation, last observation and observation time, status, body odometry, sampling mode and receiver audit counters. Per-query relative phases begin at zero and are logged at the endpoint. A cache stores only deterministic solves keyed by the permitted normalized input; it changes cost, not results. No future evidence is precomputed. Clearing episode state clears cache and counters but preserves learned readout and actuator gain.

The direct raw-template attributes are removed from the candidate controller after familiarization. The familiarization audit retains the presented captures, but observation logic does not read that audit or recompute ordinary template distances; it uses the learned weights. This is a checked code-path boundary, not physical deletion of every exemplar copy or a security sandbox. The legacy comparison controller retains its ordinary templates. Both have the same prior information. Familiarization itself occurs before episode evaluation and is not counted as an animal learning result.

The carrier is formed algebraically at the requested observation times; its waveform is not integrated as an additional conductance or voltage variable. On the main task's integer clock, the chosen carrier completes integer cycles. The separate arbitrary-angle checks test cancellation away from that grid. Thus this implementation is a phase-coordinate dynamical hypothesis with an algebraic carrier readout, not measured ongoing sensory oscillation.

Every case receives the same 24 previously used development episodes. Every event logs observations, receiver/readout evidence, action, actual return and evaluator truth separately. The evaluator cannot be called by the controller. Record all adverse outcomes, including colored-illumination failures and any effects of learned-weight corruption. No best-sign selection or retuning follows the runs.

## Claim boundaries

This construction can establish that the declared algorithm is connected, uses learned receiving state and obeys the measured observation/action boundary. It can expose which changes causally affect its own behavior. It cannot show that flies use these equations, that anatomy determines their parameters, that higher performance follows from phase, or that the generated internal relation is experience. A conventional matched comparator and a coordinate-equivalent interpretation remain essential even when the application works.
