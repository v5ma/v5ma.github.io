## Reproduction and resource boundary

The producer is [test_hue_subset_envelopes.py](../../../access/bd452038b00435c1.md).
The separate checker is [check_hue_subset_envelopes.py](../../../access/553e399b2f35888f.md).
They reject an existing output directory and preserve accepted results. A new
replay must use a new versioned destination and retain the source pins. The
producer took 9.812 seconds and the separate checker 1.375 seconds in this
environment; elapsed times are run observations, not guarantees.

One below-normal-priority foreground process, one numerical/reader thread,
64 MB DuckDB working memory, D-owned outputs; no installations or broad search.
The source verification and numerical checks share one analyst. No independent
review, native export reproduction, fitted circuit or held-out validation is
claimed. The full receiving/PWD/NAPOT/multimodal/action-return/learning paper
remains in development.
