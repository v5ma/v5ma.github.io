# Prisco/Dryad selected-workbook inspection

22 September 2026. This is a reproducible, **descriptive** readback of four public files acquired from [Prisco et al.'s Dryad dataset](https://doi.org/10.5061/dryad.bk3j9kdd1). Each input passes a byte-count and SHA-256 comparison with its [Dryad metadata and acquisition receipt](../../../access/51a5760223194112.md). Run [the analysis](analyze.py) with the bundled Python environment; it reads the three workbooks, verifies the README source file and writes [results](results/RESULT.json) and a [Figure 5C descriptive redraw](results/figure-5c-descriptive.png). The plot was inspected at full resolution.

The Figure 5C workbook reports five plane-level means, SEMs and `n=8` in both ratio series at every plane. The five displayed PA/MP means are 3.20, 2.39, 2.03, 1.79 and 1.69; FA/MP means are 1.42, 1.31, 1.24, 1.13 and 1.04. Straight lines through those **five summary points** have slopes -0.362 and -0.094 per plane. These slopes are arithmetic descriptions only. They do not reproduce the paper's inferential regression or establish an animal-level effect.

An unresolved source discrepancy must be reported before promotion: the [eLife Version of Record Figure 5C caption](https://elifesciences.org/articles/74172) states `n=7`, whereas the selected official Dryad workbook displays `n=8` in each plane. The selected file has no animal identifiers or individual traces with which to reconcile those counts. Possible differences in what is counted must be checked with the authors' source materials; neither value should be silently chosen as the definitive biological-replicate count.

The Figure 4B/4D workbook has ten nonempty numeric rows, each with four condition blocks of Mean, SD and N. The inter-odour supplement has ten rows; one second-column value is missing. The [follow-up dependency audit](../../reviews/FIGURE-4B-4D-SUPPLEMENT-DEPENDENCY-AUDIT-20260922.md) verifies that all ten APL ON and all ten APL OFF supplement delta cells are exact same-row `Oct Mean − Mch Mean` calculations from the Figure 4 workbook. They are **not twenty additional independent observations**. The source reader now records the ten-row condition means and 20/20 identities. The inspection does not assume that rows across conditions identify the same fly, and it does not derive new p-values by treating ROI counts or planes as independent animals. The Dryad README says the deposit contains primary figure data and processing code, but these four small selected files do not contain the complete raw imaging records or native timing needed for phase analysis.

This result strengthens source custody and makes the local inhibitory-normalization component inspectable. It does **not** verify a SAN PWD, arbitrary receiving-port control, NAPOT, a fly self-world rendering, or experience. The Fly Brain manuscript remains Draft 20; this intake is held as a source-audit successor until the count and grouping questions are resolved and a declared figure-level analysis is reviewed.
