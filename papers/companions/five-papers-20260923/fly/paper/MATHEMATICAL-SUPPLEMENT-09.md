# M13: learned receiving inversion and finite-catalog query value

19 September 2026. Elementary conditional analysis of the [multiview application](application/multiview-query-v0/README.md). These are not new general theorems, new Lean results or biological confirmations. They explain both the construction and its observed equivalence to the direct comparator.

## 1. What the receiving model actually computes

Let x=(p₀,p₁,p₂,p₃,d), with p channels ordered as the engineering population coordinates Rh3/pR7, Rh4/yR7, Rh5/pR8 and Rh6/yR8. Opposite members within the declared pale/yellow pairs are j=(2,3,0,1). The proposed linear rate deviations follow

dpᵢ/dt = −pᵢ + qᵢ − k pⱼ₍ᵢ₎ + c d,

dd/dt = [−d + e(p₀+p₁)/2 − h(p₀+p₁+p₂+p₃)/4]/τd.

All coefficients, operating points and time units are engineered. The four source ERG shapes do not calibrate these rates. The model includes a direct paired inhibitory route, separately removable input to the pooled state, a parallel excitatory input and separately removable positive output. It omits voltage/receptor kinetics, nonlinear thresholds, real spatial surround, measured delays, indicator dynamics and endogenous oscillation.

Write this as dx/dt=A x+B q, with B injecting into the four p coordinates. The implementation uses four explicit Euler substeps with fixed input q, T=I+Δt A, so

x_next = T⁴ x_previous + G q,

G=Δt (I+T+T²+T³)B.

This formula is the exact discrete implementation, not an assertion of exact continuous integration. For the intact declared parameters, the maximum absolute row sum of T is 0.975. For two trajectories driven by identical inputs, their difference after n substeps therefore obeys ||Δx_n||∞≤0.975ⁿ||Δx_0||∞, by the induced-norm inequality. This proves contraction of this particular discrete map. It does not identify a physical relaxation time or establish a native phase mechanism. A stable linear system can have damped complex modes; this one does. The [mode audit](application/multiview-query-v0/controls-01/EIGENMODES.json) preserves that distinction. The plan's phrase “not an oscillator” must not be read as excluding transient ringing; no measured or self-sustained tonic oscillation is supplied.

## 2. Why a learned readout can undo this receiving transform

Let C select the four p coordinates and H=CG. If H is invertible and the readout has the previous five-state vector as well as current p, then

q = H⁻¹[p_next − CT⁴x_previous].

Proof: apply C to the discrete state equation and rearrange. This is a conditional observation inverse. It depends on the stated prior-state access and linear model; it is not a claim that biological downstream cells have that access or that all receivers are invertible.

The public calibration trains a linear readout from ten features: four current p coordinates, five previous-state coordinates and a constant. With a full-column-rank teaching matrix X and exact targets Y generated by this model, unregularized least squares uniquely recovers the linear inverse on these features. With the implemented positive ridge penalty λ, Wλ=(XᵀX+λI)⁻¹XᵀY, so the coefficients need not be exactly equal. No exact identity is asserted for the ridge solution or arbitrary novel inputs.

The [numerical control](application/multiview-query-v0/controls-01/CONTROLS.json) finds rank 10 in the fixed teaching matrix and rank 4 in H. The analytic inverse reproduces the 512 teaching inputs within 5.00×10⁻¹⁶; the learned ridge readout's maximum teaching discrepancy is 1.43×10⁻¹⁰. The maximum coefficient discrepancy is 2.84×10⁻⁹. These are numerical, finite-data checks of the declared matrices, not a formal rank proof over real-valued biological parameters.

This explains why successful receiving-to-query behavior does not establish that the receiving dynamics are indispensable: the construction expressly teaches their inverse. The direct learned comparator can therefore preserve the same task-relevant information. Matching all 576 actions between the intact candidate and the direct comparator is a measured finite result, not a theorem of universal equality under noise, lesions, unknown state or nonlinear receiving. A future physiological claim must specify which variables are truly available and what consequence remains identifiable under the relevant intervention.

## 3. Query value inside the learned finite model

Let wᵢ≥0 sum to one over candidate types, and let aᵢ∈{0,1} be the learned action-relevant key. With zero-one loss, the risk before an additional observation is

R=min(Σₐᵢ₌₀wᵢ, Σₐᵢ₌₁wᵢ).

Suppose a prospective view partitions the candidates into groups G. Its model-expected residual risk is

R_view = Σ_G min(Σᵢ∈G,ₐᵢ₌₀wᵢ, Σᵢ∈G,ₐᵢ₌₁wᵢ).

For nonnegative numbers, Σ_G min(a_G,b_G)≤min(Σ_G a_G,Σ_G b_G). Therefore 0≤R−R_view≤R. A view whose groups each have only one key gives residual risk zero. A view that does not separate the current candidates gives risk reduction zero. The program uses uniform weights over its surviving candidate set and a deterministic tolerance-based grouping of learned view prototypes. Distance weighting additionally affects which object is queried; the bound does not make this greedy choice globally optimal.

The partition is a learned model prediction, not evidence that the next physical view will follow it. Illumination changes, incomplete repertoires, changed objects and an inadequate observation model can invalidate its predicted usefulness. No calibrated subjective uncertainty, universal sample complexity or biological information gain is established. This is a conventional active-sensing calculation used to make a particular source requirement executable, not a novelty claim for information-directed action.

## 4. Causal and empirical scope

The paired-world control starts with identical permitted observations and different hidden keys. It produces identical pre-query state and action, then different evidence and actions after the shared query. This exercises the already stated M7 observation boundary. Swapping only retained unobserved-view prototypes changes the selected query; restoring them without training restores that query, while the current-view prototypes and receiving decoder remain unchanged. These are causal controls on this software mechanism.

The primary state/readout decoder and a direct comparator have identical main-case actions. Thus the present application establishes an internally used learned relation and query route, not a unique role for the proposed receiving architecture. This result neither refutes nor completes the broader SAN account.
