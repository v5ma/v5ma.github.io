# Mapped-intervention diagnostic v0.4: frozen before execution

22 September 2026. This is a **negative identification control**, not a neural fit. The specified three-slot branch route labels event `t` by `t mod 3` and appends its content to an ordered history unless its branch label is blocked. The comparator stores the same ordered history in one logical unit, with three indexed positions, and an intervention erases positions whose index has the same `mod 3` label. The routes have the same declared three content positions and the same external symbol stream. No learning, recovery, noise, energetic equivalence, or physical/anatomical equivalence is claimed.

Freeze the alphabet `{A,B,C}`, three-event horizon, all 27 ordered inputs and all eight subsets of blocked labels `{0,1,2}`. For every input/mask pair, compare the emitted ordered content, retained-event count and exact masking positions. The principal result sought is whether a mapped logical-position intervention can duplicate the branch-route output under all 216 conditions. The positive example `ABC` with label 1 blocked should yield `AC` in both routes. Retain latent-route difference and do not call the logical position an anatomical dendrite.

The conditional analytic statement is: for any finite horizon, input sequence, number of branch labels `n>=1`, and blocked-label set, if the one-unit comparator applies exactly the same position predicate as the branch route, their visible retained histories agree by induction. This tests identification limits even when a named label is blocked; it does **not** imply that a real branch can be targeted by manipulating an abstract memory index. A genuine biological discriminator requires independent localization, measured local activity and a control intervention matched for its effect on content, state and output.

Acceptance checks are frozen as: all 216 cases enumerated once; all visible outputs, retained counts and mask positions match; passive no-block outputs preserve each input; latent route labels differ from one-unit routing on `ABC`; `ABC` label-1 block gives `AC`; each single-label block preserves two events for all length-three inputs; full block yields empty output; `ABC` and `CBA` remain distinct with label 1 blocked; and a byte-identical rerun. A failure is recorded, not silently repaired after inspection.
