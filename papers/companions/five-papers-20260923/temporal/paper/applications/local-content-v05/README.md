# Local content-bearing compartments and the aggregation boundary

23 September 2026. [Frozen protocol](PROTOCOL.md), [implementation](model.py), [complete result](run/RESULT.json), [replay](replay/RESULT.json), [independent state audit](AUDIT.json), [audit/figure source](audit_and_figure.py).

The model now has explicit local content matrices, two decay times, local adaptation, continuous competitive activation and a downstream action choice. There is no ordered-history list in its readout and no externally assigned branch order. In the fixed six-time-unit observation window, baseline two-, three- and four-component models have 6, 8 and 9 changes in the most active component. Removing adaptation or mutual inhibition removes those switches. These are numerical rate dynamics under constant drive, not a proof of stable periodic or biological oscillation.

All 576 separated-event cases choose the specified order-dependent port; the 144 simultaneous cases correctly report that order was not supplied. All 720 provided object-feature conjunctions retain their ownership. The deliberately weak independent-marginals control cannot distinguish the two assignments. The stronger ordinary nonoscillatory state bank agrees with the local model to at most 2.22e-16. Results replay byte-identically. The original producer passes 4,320 arithmetic/contract assertions; the separately written audit reconstructs the state directly from event kernels. Counts are not independent observations or effect sizes.

This adverse control is exact, not an unsuccessful search for advantage. Because receiving weights sum to one and each compartment has the same two decay constants, summing the local states removes the allocation mechanism. The aggregate obeys the same event-driven recurrence as a nonoscillatory two-timescale memory. Removing local adaptation or coupling therefore does not damage these decisions. Erasing the retained content removes the order decision, and restoring it restores the decision. This proves content use in this program, not the necessity of alternation.

The pair code is given as an outer product of a supplied object label and feature label. The program preserves supplied ownership; it does not discover scene segmentation or bind ambiguous sensory features. The time grid approximates the rate equations; it is not a measured neural frame rate. The elementary order readout is restricted to two events and the frozen delay/gap grid. Exact calculations are noiseless. Heterogeneous recovery is tested, but trace decay is shared across compartments, so the aggregation result still applies. No learned recurrent comparator, physiological fit, biological phase reference or consciousness claim is supplied.

The next distinctive test needs a justified operation that prevents aggregation—such as branch-sensitive downstream coupling, saturating local capacity or independently measured heterogeneous content decay—and a fair state-based alternative. It would be inappropriate to insert an artificial dependency merely to make alternation appear necessary. T03 is partially addressed by local-state construction and explicit downstream use; its stronger physiological and alternation-specific claims remain open.
