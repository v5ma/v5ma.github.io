# Endogenous branch-selection toy, not a dendritic fit

Run `python model.py`. It writes `results/RESULT.json` and checks an intrinsic readiness-plus-competition selection rule. Unlike the first application, branch order is **not supplied as a schedule**. With constant drive, a global winner-take-one constraint, a readiness threshold, and post-use fatigue, the toy chooses branches `0,1,2,0,1,2`. Removing fatigue repeats branch `0`; disabling competition permits concurrent branches. Blocking branch `1` introduces pauses and different selection. Restoring it restores the baseline pattern.

The selection rule is deliberately simple and engineered to make alternation possible. It is not a fitted electrophysiological equation, proof of spontaneous biological oscillation, or test of consciousness. An equally event-budgeted single-branch system can still preserve `ABC` in timestamped history; the model therefore does **not** show that alternating compartments are necessary for sequence information. The next biological experiment must measure actual branch-specific recovery and coupling, then test the model prospectively under activity- and information-matched perturbations.
