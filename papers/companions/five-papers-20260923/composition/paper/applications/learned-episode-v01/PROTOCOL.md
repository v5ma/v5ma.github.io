# Learned episode development protocol — implementation 1

Frozen before this implementation's first execution, September 8, 2026. The preceding v0.1 specification is preserved. This implements a deliberately small subset; it is not the strong recurrent-model comparison or a neural/PWD simulation. Source and configuration hashes are written before training and bound to the outputs. Any bug-fix rerun remains development, never retrospectively untouched confirmation.

## What is actually learned

Two channel codebooks assign opaque symbols to four fine values or two coarse bins. Labeled training calibration learns symbol-to-value associations. A tabular controller then estimates mean rewarded utility for every available plan under each opaque task cue and episode stage. It receives reward only during training. Evaluation freezes both associations and plan values. Query semantics and the finite plan grammar are supplied by the programmer; the controller learns which plan to select, not that grammar, the task definitions, biological memories or a neural representation.

The environment has three entities and two channels (six four-valued coordinates). The action grammar contains all one-, two- and three-coordinate subsets plus the complete six-coordinate set. A plan chooses a subset, coarse/fine sampling or retention, and current sampling, reference-event retrieval, or both. Plans requiring more than six operations are excluded. This is learned macro-action selection rather than within-query adaptive micro-actions. Parameter-learning is exhaustive balanced exploration of plans on training episodes, not a claim of sophisticated reinforcement learning.

Every episode starts with six explicit fine observations of its reference scene, identically supplied and charged to all conditions. This controlled familiarization provides the archive used to distinguish present assembly from available earlier evidence; it is not learned anticipatory acquisition. A first query concerns the present scene. Then the world changes, a different task cue arrives, and a second query may concern the new scene, the reference scene, or their temporal relation. Current sampling returns only the requested coordinate at the requested granularity. Retrieval returns only previously observed records. No agent function receives hidden world values or target labels.

Six tasks use opaque IDs. Their declared readouts concern a fine value in coordinate 0 or 5; coarse values across coordinates 2, 3 and 4; an ordered fine pair in coordinates 1 and 3; a delayed fine pair in coordinates 0 and 5; and whether coordinate 4 increased, stayed equal or decreased since the reference event. These are symbolic channel/entity relations, not six realistic human occupations. A learned value decoder plus the declared readout computes responses. Missing or insufficiently fine evidence produces a fixed zero-valued response, not an oracle completion. Its chance-level successes remain in the scores.

## Splits, counts and bounded execution

For each of the three configuration seeds, shuffle the 4,096 instantaneous states once into 2,867 training, 614 development and 615 evaluation states. All encountered marginal symbols must appear in training. Draw disjoint-world episode pairs only within their split. Training explores 32 pairs for each valid stage/task/plan. Parameter freeze occurs before constructing the evaluation episode sequence; report exact sequence hashes and verify that no evaluation world was used in calibration or fitting. The small smoke mode uses development states only. The later evaluation is still a development test of the authored synthetic family, not an independently designed generator or confirmatory test.

The first query uses one of the four current-scene tasks. The second uses a different task, giving 20 task-pair orders, four repetitions per seed, 80 episodes/160 queries per condition per seed. Every condition receives the same episode pairs and learned parameters. Episodes are the paired repeated unit; the three seeds are not human subjects. The same finite generator designs the questions, so success is not independent evidence for SAN.

Run one below-normal-priority CPU process, no GPU, network, downloads, or directory search. The smoke run is bounded at 10 seconds and the complete process at 90 seconds; aborting does not promote partial outputs to a result. Store aggregate training plan counts/returns, all evaluation actions and queries, frozen learned parameters, compact provenance, and at least one success/failure trace. Do not emit training raw world arrays into the conversation.

## Conditions and accounting

The matched attention condition is an explicitly equivalent selection/readout interpretation using the same fitted controller; equality is a representation-label control, not an independently trained strong baseline. The full-record baseline receives all six current fine samples and the archive, so it is an information-rich upper bound. Fixed-all-coarse uses six coarse samples. The other conditions leave fitted parameters intact and intervene at the second query: delete prior episodic records; permute entity bindings; undo that permutation; coarsen only the assembly after source acquisition; remove reference-time entries only from the assembly; reverse time labels; or deny new observations after the world change. Frozen probes receive the assembly only, with no archive or sampling access. An inverse binding map restores an encoding; it does not regrow lost information.

Utility during training is exact response accuracy minus separately declared acquisition-bit, assembly-bit and operation costs. Report accuracy by task and condition, paired episode scores, selected coordinates, sampling and retrieval counts, acquisition bits, retained assembly bits and actual serialized record size. Familiarization cost is reported separately and in total acquisition; do not describe these counts as metabolic energy or end-to-end compute. The controller is a table lookup, whose lookup and training-evaluation counts are reported rather than hidden in a source-bit efficiency slogan. There is no confidence head and therefore no calibration result.

## Acceptance and limitations

Tests cover learned changes, split separation, observed-only memory, action-to-return dependence, frozen evaluation parameters, task/target separation, replay, and intervention identities. Independently recalculate logged accuracy from environment targets; independently reconstruct the selected plan's sufficiency from its coordinates/time coverage. Unit checks can pass when a comparison loses. Report all such losses and ties.

This application does not implement oscillatory physiology, human memory richness, stochastic neural noise, pharmacological states, internally learned task semantics, long-horizon planning or a modern recurrent attention model. Its value is an inspectable learned selection process with controlled distinctions among stored evidence, current assembly and downstream response. The stronger application remains a later development stage.
