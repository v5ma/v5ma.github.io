# Learned active episode classifier - prospective local protocol

September 8, 2026. New application family, motivated by the preserved neural temporal failure. Frozen before its fitting runs. The earlier recurrent encoders, applications and held-out files are untouched. This is a conventional supervised, cost-sensitive query-tree comparator with an encountered episodic store, not a neural implementation of SAN or completion of the full learned-recurrent/active-acquisition gate.

## Acquired and supplied components

Labeled training episodes teach a separate categorical query tree for each opaque task ID. Each node selects one view or a pair of views by empirical label-entropy reduction divided by declared view cost. Children and smoothed response probabilities are learned from training counts. Evaluation never calls a task-answer formula inside the agent. The current task label, finite sensor interface, coarse/fine conversion, structured memory store, tree grammar, heuristic and supervision are supplied. This is offline supervised acquisition-policy learning, not reward learning, an optimal long-horizon controller or learned neural memory.

The world has two successive observations, each containing six four-valued coordinates. These are symbolic dimensions, not human sensory recordings. Five nonfocal old and five nonfocal new values form a background. Each background contains all eight old focal-value and clockwise/counterclockwise neighbor combinations at coordinate 4. This preserves exact single-focal-view, unordered-pair and coarse-pair temporal balance. New independent seed-specific background sets are used, not the earlier evaluated dataset. Familiar symbols and rules occur in every split; new backgrounds are not new semantics or external biological validation.

Eight opaque task IDs request current coordinate 0, current coordinate 5, the three coarse current coordinates 2/3/4, the ordered current fine pair 1/3, the old fine pair 0/5, the circular old/new relation at coordinate 4, a conditional task, or current coordinate 4. The conditional task outputs 0 when current coordinate 2 is in its lower coarse bin; otherwise it outputs 1 plus current coordinate 0. Task formulas belong to training-label creation and evaluation only. The conditional task makes the usefulness of another fine observation depend on an encountered coarse observation.

## Three-query episode and information contract

There is no free complete familiarization. The first query concerns the reference scene and uses one of the six current-scene tasks. Its requested observations become the only available reference memory. The world then changes and the second cue arrives. A third, different cue concerns that same new scene; current evidence obtained at query two can be reused. Temporary assembly is cleared between queries, but encountered memory persists. Before the scene changes, old/current coordinate references alias the same encountered scene; the agent cannot inspect the future scene.

For each background and possible second task, choose the first current-scene task deterministically from the declared list, moving to the next list entry if it equals the second. The third is the second plus three modulo eight. This rule is fixed within a complete eight-case focal block and does not inspect target values. A source request returns only that current coordinate at the chosen granularity. Missing reference observations cannot be sampled retroactively. A query stops at a learned leaf or an unavailable required view; the latter uses the tree's count-weighted prediction under the available evidence, not the hidden correct answer.

Every policy request records its coordinate, requested precision, source (new sampling, stored retrieval or unavailable history) and returned value. A two-view node selects both views before branching, so this is bounded lookahead, not arbitrary within-node replanning. Subsequent tree nodes depend on the observed values. No task answer, background ID, case ID, seed, split or raw world vector reaches the policy.

## Tree fitting and controls

Three seeds, 128 training background blocks per seed, 16 development blocks and 16 held-out blocks. Each block has eight cases. All training classes must occur. Fit all four families on identical examples: paired coarse/fine views, single-view coarse/fine, paired fine-only, paired coarse-only. Candidate views of the same coordinate are not paired. The rule uses information gain in bits divided by source-bit cost plus 0.1 per requested view; this heuristic is not the true realized episodic acquisition cost or a certified optimal policy. Tie tolerance is 1e-12, then fewer views and lexicographic feature IDs. Maximum depth is eight, minimum split gain 0.02 bits, minimum leaf size four, and leaf smoothing is 0.5 per legal class. Stop on purity, depth or an unavailable acceptable split. Preserve all learned families, including failures. There is no checkpoint selection.

Evaluation conditions are the paired learner; its exactly equivalent ordinary-attention interpretation; the single-view learner; fine-only and coarse-only learners; an information-rich full-record control with the paired learner; removal of stored reference memory at the switch; no new sampling after the switch; assembly-only coarsening after acquisition; binding permutation; and inverse binding restoration. The full-record condition explicitly samples every reference coordinate before the first query and every new coordinate after the change. It is not information- or cost-matched. Assembly interventions change neither sampling nor the stored cache. The binding permutation swaps coordinates 0 and 1 within each time slice. The inverse restoration must reproduce the original assembly and prediction exactly.

The equivalent attention condition is not a separately trained strong model. The single-view ablation intentionally removes pair lookahead; coarse-only intentionally removes fine access. Neither is a caricature of all modern attention or active-acquisition research. A tree is also not a fair architectural substitute for a published recurrent gating system. These comparison boundaries remain explicit.

## Freeze, evaluation, metrics and limits

Before fitting, record hashes of this protocol, configuration and all implementation/test/evaluation files. Fit and freeze every seed/family before constructing any development or held-out cases. The evaluation runner first verifies frozen hashes and writes its before-evaluation receipt, then constructs the new cases. Development results are descriptive, not used for selection in this version. A bug-fix rerun would remain exploratory and would require a new version; no inspected evaluation becomes untouched again.

Record every query's probability vector, target, sampling bits, sampling/retrieval counts, requested views, encountered cache, final assembly and tree work. Count supplied complete observations in the upper control. Report query-stage and task-balanced accuracy and log loss, conditional-task sampling dependence, order and reference dependence, unused detail and actual retained fields. Source bits are not metabolic energy or total computation. One background is a repeated unit across its eight cases, eight role triples and all conditions. Three seeds are not participants. Report seed variation; bootstrap only paired background summaries conditional on the fitted models, with that limit explicit.

Resource limits: one below-normal-priority CPU process and one numeric thread; no GPU, download, service, recursive search or subprocess fleet. Each fit is capped at 20 seconds, total training at 120 seconds, each evaluation at 90 seconds. A deadline preserves completed work and an incomplete status, not a claimed complete result. Compact arrays preserve full per-query evidence; JSON traces are bounded to selected successes/failures. All writes stay in this new paper's application folder.

Acceptance requires observed-only action interfaces, no future disclosure, no hidden target calls inside agent code, disjoint backgrounds, exact temporal shortcut checks, changed learned parameters, actual action-conditioned returns, stored-history use where available, complete failures/ties, and exact numeric replay. These establish software and measurement facts only. They do not establish conscious experience, a PWD mechanism or superiority over the cited modern literature.
