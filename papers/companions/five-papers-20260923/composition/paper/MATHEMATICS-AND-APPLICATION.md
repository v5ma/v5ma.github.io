## What has been established

Draft 1, Section 4 contains three hand proofs for a declared finite deterministic representation model. They are elementary known mathematical consequences, included as an auditable specification rather than asserted new theorem discoveries.

1. **Task sufficiency:** a target factors through a representation if and only if it is constant on every representation fiber. Readouts are defined on attainable representation values, avoiding an unnecessary assumption about unattained codes.
2. **Refinement monotonicity:** if a coarse representation is a function of a finer one, unrestricted readouts can match or improve minimum loss under the same distribution, target and bounded loss. Restricted or poorly trained decoders need not achieve this bound; extra cost can outweigh an accuracy benefit.
3. **Incomparability:** the two coordinate projections on a binary square are each sufficient for their own target, but neither determines the other. A scalar count of code values therefore cannot identify which task distinctions survive.

The exact optimal zero-one-loss evaluator follows by choosing a most frequent target in each fiber. An invertible relabeling preserves this evaluator. A separate analytic Gaussian example shows why gain preceding fixed noise can improve discrimination. A slot swap is an invertible binding mismatch for a fixed decoder, not destroyed information.

The preserved Draft 1 claimed no Lean file or compiler-checked theorem. Later additions are mapped above, not projected backward into that version. Finite executable checks are not substitutes for universal proof or biological validation.

## Why a stronger application is still necessary

The current selector is given the role and target coordinates. There is no learned memory, sequence, active sampling or neural dynamics. A next-phase application must learn composition/granularity control in a closed loop, test withheld combinations, preserve strong conventional comparators, and measure total system cost. Until then, the application supports definitional consistency and transparent counterexamples, not the entire biological or experiential thesis.
