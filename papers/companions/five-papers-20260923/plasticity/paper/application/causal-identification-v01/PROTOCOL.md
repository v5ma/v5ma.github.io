# Correspondence, differential course and later change: identification stress test

23 September 2026. Pre-run contract. This is a mathematical diagnostic plus a bounded field audit, not a new biological reanalysis. Read only the already acquired two cell-7 records, their existing six-source hash ledger, and their headers. Do not search for or download new data.

The paper proposes separately measured pre-event correspondence C, event course D, eligibility E, instruction P and later receiving change Y. Test the inference that observing all five, with a strong association and temporal order, would by itself identify a causal effect of D on Y.

Define latent receiver state U, unrelated output variation N, D=C+U, and g=EP. Model A has Y=g(0.3 C+0.7 D)+N. Model B has Y=g(C+0.7 U)+N and no D-to-Y arrow. They agree on every unperturbed observation because substitution cancels the distinction. Under an ideal intervention adding delta to D while holding C,U,E,P fixed, Model A changes Y by 0.7 g delta and Model B does not change Y. This is a constructed nonidentification proof, not a proposed physiological linear law, real effect size, or feasible experimental perturbation.

Use exact rational arithmetic over C in {0,1/2,1}, U in {-1,0,1}, N in {-1/10,0,1/10}, E/P in {0,1}; 108 states. Perturb D by 1/4. Preserve all outcomes; report gated and ungated cases separately. An ideal intervention is not identified from its commanded waveform: actual effects on E, P, inhibition and other receiver states must be measured.
