## Revision scope

The Hesse/Tsao comparison separates represented content from selected downstream use, state occupancy, encoding strength and receiving influence. The review clarifies prospective tests, randomization/selection scope, matched alternatives and reproduction availability. See [review findings](REVIEW-FINDINGS.md) and [source locators](HESSE-CLAIM-BOUNDARIES.json). Existing application outcomes, adverse comparisons and the stronger SAN experience hypothesis remain. No new biological data, physiological fit, source-data reanalysis or independent peer review is claimed.

## Reproduction

Run `python -B analysis/check_state_selection.py` for seven small constructed arithmetic checks; no downloads, model fitting or training are started. These checks do not reproduce the Hesse recordings or validate consciousness. The calculations use ordinary Python and the standard library.

The original five applications, earlier figure protocols and their frozen results remain in the [version 1.0 companion](https://github.com/v5ma/v5ma.github.io/tree/f6d3867df89ae9dea32f763b1d55c84212c41cc6/papers/companions/five-papers-20260923/temporal). This smaller update does not duplicate that entire archive; use both versions for the full source trail.
