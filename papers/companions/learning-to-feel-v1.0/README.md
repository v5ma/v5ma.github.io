## Status and scope

Initial author-authorized public release, derived from frozen Draft 34. This is a hypothesis/formal-model preprint, not a peer-reviewed article or a report of a new biological experiment. Conditional proofs, five constructed applications, negative/tied comparisons, six prospective predictions and the stronger SAN experience hypothesis are preserved. Publication preparation changed status text and link destinations, not the scientific results. No new model fits or biological analyses were run for this release.

AI assistance was used in research exploration, drafting, mathematics and code development. Automated checks are not independent scientific/statistical peer review. The prospective human study is unregistered and requires feasibility, statistical and ethics review before execution.

## Reproduction boundary

The selected original JavaScript programs use Node.js built-ins and retain their original hashes. Their saved JSON outputs are included. Programs differ: some only print results, some perform learning calculations, and some require explicit replay/save arguments. Read each program before execution; this package does not start any computation automatically. External comparator code and the full native replay environment are deliberately excluded; see artifact availability. No new compiler/proof-assistant validation is claimed by publishing these sources.
