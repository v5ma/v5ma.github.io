## Reproducibility & Workflow Distinction

1. **Replay all 10 required scientific verifiers and run the standalone portfolio audit (fully self-contained & non-destructive on any clean checkout):**
   ```bash
   python shared/verify_portfolio_pass2.py --execute-verifiers
   python shared/verify_portfolio_pass2.py
   ```
   - **Fresh isolated replay (`--execute-verifiers`):** Enforces the explicit 10-script `REQUIRED_VERIFIERS` registry (failing closed immediately if any script is missing or renamed) and executes each verifier inside a clean temporary directory containing only the verifier script and its sibling `Candidate.md` (with zero pre-existing JSON files, so stale outputs can never mask a missing or broken verifier). It validates every freshly written result's `overall_passed`, expected `check` IDs, and manuscript hash binding without modifying committed `paperXXX_*_verification_results.json` or `PORTFOLIO-PASS2-AUDIT-RECEIPT.json` on disk. Pass `--report-out <path>` to save a separate replay report JSON, or `--write-receipt` only when intentionally refreshing the committed audit receipt.
   - **Offline integrity mode (no flags) & cross-platform floating-point note:** Verifies exact SHA-256 identity of every committed Markdown, TeX, PDF, verifier script, and committed verification JSON against `PAPER-XXX-BUILD-RECEIPT.json` and `PORTFOLIO-UPGRADE-MANIFEST.json`. Across different CPU/BLAS runtimes, fresh numerical execution of Papers 014 and 034 can produce harmless `~1e-15` floating-point roundoff differences in diagnostic residuals that do not affect any pass/fail outcome; because `--execute-verifiers` executes in isolated temporary directories and preserves committed JSON receipts, running offline integrity audit immediately after fresh replay passes cleanly on the same working copy. In a standalone checkout without the historical July 2026 donor archive, the script records `audit_mode: "standalone_checkout"` and explicitly reports that historical donor-heading comparison was skipped.
2. **Re-render an existing `Paper-XXX-*-Candidate.md` to Hydrogen house-style PDF (self-contained with vendored helpers):**
   `shared/build_paper.py` uses vendored `shared/house_style_header.tex` and `shared/house_style_tex_helpers.py` (enforcing zero XeLaTeX `Missing character:` warnings) and locates `pandoc` and `xelatex` via `PATH` (or `PANDOC_BIN` / `XELATEX_BIN`). It re-renders any committed `Candidate.md` directly without external workspace imports and binds `markdown_sha256`, `tex_sha256`, and `pdf_sha256` into `PAPER-XXX-BUILD-RECEIPT.json`.
3. **Regenerate `Candidate.md` from historical July 2026 baseline donors (requires external archive):**
   The donor-to-candidate builder scripts (`paper-*/build_paper*.py` and `shared/build_wave4_all.py`) read the immutable July 2026 public-markdown donors from the external historical release directory outside this commit (`../78-paper-house-style-release-20260729/build/public-markdown/`).
