# Preserved Aether proposals, not live gameplay

These inert .reference files preserve public source from the unmerged Tideglass Reservoir and living-city proposals. They are not imported by the game, included in its runtime manifest, or offered as alternative playable entry points. Restoring this material to active code requires a forward port, not a branch merge.

SOURCE-MANIFEST.json records original paths, branch heads, actual synthetic PR-merge commits tested by the downloaded artifacts, and byte digests. The original branches and commits are retained as complete integration history. A PR can be closed without treating its proposed features as implemented.

Preserve these ideas, but require integration with current collision, licensed cast, save/mission data, direct controller input and every supported XR mode before exposing them in the normal game. Do not import its old app, model, renderer, source writer or refiner.

The authored-worlds policy/abstract graph and Aurora renderer are separate historical branches; current Bellwether Rewired, World Portal, Clear Window, Skyglass/Grounded Cast and Field Rotunda supersede their conflicting integration assumptions. Older shader sheets, bounded-section diorama policy, version strings, complete-file replacements and temporary writer workflows are not recovery instructions.

No private SaaS hub, credentials, browser saves, sibling-game code, framework migration or travel portals are included here.
