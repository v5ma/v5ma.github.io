## What 0.11.0 adds

Tideglass Reservoir is an explorable water annex east of Glasshouse Gardens connected by physical walkways. It includes a deep basin, shallow filter pool, railed basin stairs, a climbable pool ladder, enterable pumphouse, isolation valves, gradual drain/refill, swimming/diving and repaired return jets.

`The Water Below the Sky` is a 240-credit once-only repair adventure. `Poolside Signals` is a 100-credit once-only three-plate calibration adventure. The regulator can be recovered by swimming/diving or by draining the basin and using the steps. Mission progress, isolation, plates and requested water level survive save/continue; live swimming pose, velocity and ripple state do not become arbitrary-position save data.

Controller intent is full gamepad play without needing the mouse. Normal left-stick movement swims, A surfaces, B toggles diving, X interacts/climbs, and L3 boosts. Existing remapping remains supported while fixed menu A/select and B/back behavior is retained. Submerged gun/power attempts do not consume ammunition/energy. The pause/menu surfaces the water missions and Settings has an independent water-effects switch.

Water presentation includes procedural wave normals, Fresnel-style sky approximation, sun glints, depth tint, bounded contact ripples, tiled caustics and underwater fog. These are real-time artistic approximations, not a claim of full fluid simulation, scene refraction or ray-traced reflections. Light/XR and reduced-motion paths are explicit. Water ambience, splashes, pumps and mission cues use the existing audio buses.

The old sniper browser driver was brittle under software WebGL because it made many Python/browser round trips while aiming. `aether-reach/tests/arsenal_browser.py` now uses bounded native keyboard look convergence; it still changes yaw/pitch only through ordinary game input and uses snapshots only for observation. The sniper path subsequently passed through purchase, real FOV scope, aimed hit, salvage, upgrade and save/continue.

The test now explicitly accepts that in-game confirmation. Arsenal and rails both passed on GitHub Actions run 34759798958 at feature head `1846d530a8aea6bece8dc03a9f07f840278e5bef`.

The full Node regression suite on this release line reports 226/226 passing tests. Foundry browser regression also passed on the current Tideglass workflow run 34759798963.
