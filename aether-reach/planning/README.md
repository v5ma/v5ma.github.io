# Aether Reach production planning

The current committed plan is ../roadmap.json, presented by ../roadmap.html and mirrored in AAA-ROADMAP.md. The v0.10 plan retains stable IDs and separates implementation, browser review, real hardware and publication gates. Its AAA-quality goal requires a polished vertical slice, production assets, a complete campaign, performance and accessibility acceptance; it is not a present-quality claim.

The unchanged eight-sheet Aether-Reach-Development-Roadmap-v0.3.xlsx remains an archived snapshot. Its byte and member hashes are recorded in WORKBOOK-MANIFEST.json. It is not the current plan. Browser-local board edits change neither GitHub nor game checkpoints.
