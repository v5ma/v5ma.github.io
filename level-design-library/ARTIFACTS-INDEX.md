# Artifact Index

This public folder is the agent-readable source edition of the SVGN Interactive Level Design Library.

The originating work also produced three PDF guidebooks, a 21-sheet Excel workbook, a searchable offline HTML reader, structured JSON, templates, validation reports, and a ZIP package. Those binary and generated presentation exports are derivative views of the same design work and remain available from the originating ChatGPT artifact package.

For cross-chat development, use the Markdown files in this folder as the stable public reference. They are deliberately easier for coding agents to browse than PDF or spreadsheet exports.

Public source files:

`README.md` explains scope and entry points.

`AGENTS.md` is the mandatory agent contract.

`UNIVERSAL-GAME-CHAT-INSTRUCTION.md` is the reusable instruction to paste into any game-development chat.

`STUDIO-LEVEL-DESIGN-MANUAL.md` contains the shared methodology and genre applications.

`GAME-RECOMMENDATIONS.md` contains concrete recommendations for the active SVGN games.

`SKY-CYCLE-LEVEL-DESIGN.md` is the separate Sky Cycle methodology.

`QUALITY-REVIEW-FRAMEWORK.md` defines evidence-based review criteria.

`INDUSTRY-REFERENCE-NOTES.md` records the transferable lessons from the commercial and independent games studied for this project.

The public files should be treated as a design reference, not as release authority. Each game's current source, roadmap, handoff, save contract, controls, and verification evidence must be refreshed before implementation.
