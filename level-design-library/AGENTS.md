# Agent entry contract

Read this file before applying the library.

Resolve current game identity. Read the current source handoff, release manifest, canonical task data, actual launch entry and save contract. Record the exact SHA. Never use the homepage's historic version string as sole authority.

Read the matching game brief and genre handbook. Sky Cycle requires sky-cycle-manual.md; rhythm work requires the rhythm handbook, not a map-connectivity quota. Preserve the owner's game-specific rules.

Map the proposed task ID to an existing canonical roadmap task or document why a new task is necessary. Recommendations are not implemented work. Do not recreate features that newer source already contains.

Write one hypothesis, one bounded change, one primary observation and safety/usability guardrails. Define supported actor sizes, world states, input modes, legal completion conditions and recovery. Use real engine movement and collision.

Protect current and legacy save namespaces, layout IDs, reward idempotence, remaps, user drafts, audio ownership, licenses, public/private story boundaries and concurrent sibling work. Do not reset master or clear localStorage.

Distinguish evidence classes. A model fixture is not a native playthrough. Synthetic input is not physical hardware. An observed human session is not a universal quality rating. A merge is not a served-byte verification.

Preserve unsuccessful traces and the original acceptance criteria unless a documented design decision changes the goal. Never set actor position, health, inventory or quest progress to manufacture a gameplay acceptance pass. Fixtures must be labeled as fixtures.

End with exact-source tests, evidence paths, user/device approval status, known limitations, rollback details and the next unresolved question. Update the game's real roadmap and the library's corresponding data. Do not claim a task is complete from its title, code presence or a rendered screenshot.

Publishing this library or a game change requires the owner's requested destination and scope. This public library does not authorize disclosure of private drafts or private narrative content.
