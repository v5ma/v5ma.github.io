# Public Routes

This curated public package is published from `v5ma/v5ma.github.io` on the `master` branch.

| Route | Scope |
| --- | --- |
| `mario-maker-clone/` | Web-only Mario Maker Clone / Sprocket Works package, including the current SVGN Paper Route deployment and its design log. |
| `san-wiki-shell/` | SAN reader code and empty shell data contract only. SAN article and research content is excluded. |
| `theology-wiki/` | 370 current Theology reader pages and the self-contained reader runtime. Queue, backup, `.bak`, and `.ocv` residue are excluded. |
| `theology-sources/` | 354 unchanged `.txt` AI-chat source files used by the Theology Wiki, plus a SHA-256 manifest and browser index. |
| `agent-wiki-theology-route.html` | Small public route card connecting the Theology reader, AI-chat sources, SAN shell, and Mario package. |

The Paper Route design log is available at `mario-maker-clone/svgn-paper-route/design-decisions/DESIGN-DECISIONS.md`; its exact structured source is the adjacent `FEATURE-REQUESTS.csv`.

Public URLs:

- https://v5ma.github.io/mario-maker-clone/
- https://v5ma.github.io/san-wiki-shell/
- https://v5ma.github.io/theology-wiki/
- https://v5ma.github.io/theology-sources/
- https://v5ma.github.io/agent-wiki-theology-route.html

The package is intentionally curated. It does not publish the full private workspace, Agent Wiki, SAN corpus, private credentials, desktop builds, or backend setup files.
